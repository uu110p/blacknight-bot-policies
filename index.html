2. وصف الخدمة2. Service Description

البوت هو تطبيق Discord مخصص لإدارة عملية التقديم على تصاريح الدخول لسيرفر BlackNight، ويشمل:

The Bot is a Discord application designed to manage the whitelist application process for BlackNight server, including:

  • نظام تقديم تفاعلي عبر الأسئلة والأزرار في الرسائل الخاصة.
  • التحقق التلقائي من حسابات Roblox عبر الـ API الرسمي.
  • التحقق من عضوية المستخدم في مجموعة Roblox الرسمية.
  • التحقق من عمر الحساب (60 يوماً على الأقل).
  • نظام بلاك ليست (Blacklist) لمنع الحسابات المرفوضة.
  • نظام طابور (Queue) لتنظيم عمليات المراجعة.
  • إصدار هوية رقمية ومنح الرتب تلقائياً للمقبولين.
  • أرشفة نتائج التقديم في قنوات سجل مخصصة.
  • Interactive application flow via DMs using questions, buttons, and menus.
  • Automatic Roblox account verification through the official API.
  • Verification of membership in the official Roblox group.
  • Account age verification (minimum 60 days).
  • Blacklist system to block rejected accounts.
  • Queue system to organize reviews.
  • Automatic ID assignment and role granting for approved members.
  • Archiving of application results in designated log channels.
